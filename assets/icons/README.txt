# Petunjuk Penggunaan Logo Aplikasi

Folder ini (`assets/icons/`) digunakan untuk menyimpan logo/ikon aplikasi yang ditampilkan pada halaman utama (Portofolio Mufe3 Studio).

### Nama File yang Digunakan:
1. `aksaraku.png`       -> Ikon untuk aplikasi **AksaraKu**
2. `jejak-bayangan.png`  -> Ikon untuk aplikasi **Jejak Bayangan**
3. `chameleon.png`       -> Ikon untuk aplikasi **Chameleon**
4. `prompt-notes.png`    -> Ikon untuk aplikasi **Prompt Notes**
5. `notiscan.png`        -> Ikon untuk aplikasi **NotiScan**
6. `noticatch.png`       -> Ikon untuk aplikasi **NotiCatch**
7. `autoklik-flow.png`   -> Ikon untuk aplikasi **Flow Auto Clicker**
8. `omnilabel.png`       -> Ikon untuk aplikasi **OmniLabel**

### Rekomendasi Format:
- **Format:** PNG (transparan atau latar belakang solid) atau WebP
- **Ukuran:** 512 x 512 piksel (standar Google Play Store icon)
- **Rasio:** 1:1 (persegi)

Cukup timpa (*replace*) file placeholder di folder ini dengan file logo asli aplikasi Anda. Website akan langsung menampilkan logo baru secara otomatis!
